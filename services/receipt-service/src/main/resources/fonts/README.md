# Receipt fonts

Embedded in receipt PDFs by `PdfRenderer` (subsets only).

| File | Use | Licence |
|---|---|---|
| DejaVuSans.ttf, DejaVuSans-Bold.ttf | All receipt text (English, includes the rupee sign) | Bitstream Vera licence + public domain changes (LICENSE-DejaVu.txt) |
| FreeSans.ttf | Donor names in Devanagari or other scripts, shaped by Java2D (HarfBuzz) | GNU GPL v3+ with the font exception: embedding in documents does not make the documents GPL (LICENSE-FreeFont.txt) |
